A one-page newspaper front page that sums up the world news of Friday 20 November 2026: the first Trump–Xi–Putin three-way summit in Shenzhen and its joint peace declaration, the ICJ ruling that Myanmar committed genocide against the Rohingya, Anthropic's record IPO, South Korea's exports passing $1 trillion, and the day's other big stories (Kyiv missile strike, Houthi strikes on Saudi targets, the Hormuz tanker mine blast, Gaza, the Odisha cyclone evacuations, Europe–Russia talks).

The image is drawn at run time by `main.py` with the Python standard library only — no network, no randomness, no clock — so every run writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024 PNG, under 1 MiB).
